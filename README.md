A lightweight code to generate mock gravitational wave detector data using user-defined population and arbitrary detector sensitivity. It ships five tools -- `gwforge_population`, `gwforge_noise`, `gwforge_inject`, `gwforge_fisher` and `gwforge_population_fisher` -- plus `gwforge_workflow`, which chains noise and injections into an HTCondor DAG, and `gwforge_optimal_snr` and `gwforge_estimate_psd` for the bookkeeping in between.
