   Kept out of the executable so the parsing is importable and testable, and so the
   CLI stays a thin driver like the other ``bin/`` scripts.

.. py:function:: read_injections(config, section='Injection_Parameters')

   Collect the sources to forecast.

   Accepts either parameters written inline in the configuration, or an
   ``injection-file`` pointing at a ``gwforge_population`` HDF5, optionally
   sliced with ``start-index`` and ``end-index``.

   :param config:
   :type config: configparser.ConfigParser
   :param section:
   :type section: str

   :returns: One dict of parameters per source.
   :rtype: list of dict

   :raises ValueError: If the section is missing or defines no source.

.. py:function:: prior_settings(config, order, section='Priors')

   Read the ``[Priors]`` section and enforce the order-dependent rule.

   Order 1 is a closed-form covariance and needs no prior; order 2 samples a
   truncated Taylor expansion, which is only meaningful inside bounds, so a
   prior file is required there.

   :param config:
   :type config: configparser.ConfigParser
   :param order: Expansion order, from :func:`fisher_settings`.
   :type order: int
   :param section:
   :type section: str

   :returns: With keys ``prior_file`` and ``enforce_physicality``.
   :rtype: dict

   :raises ValueError: If ``order >= 2`` and no ``prior-file`` is given.


.. py:function:: segment_duration(parameters, minimum_frequency, approximant, f22_start=None, maximum=None, minimum=None)

   Segment length long enough to hold the signal.

   Getting this wrong is not a subtle error: a segment shorter than the inspiral wraps it, and the
   resulting derivatives are meaningless.

   :param parameters: Source parameters; needs component masses and aligned spins, which are
                      derived from whatever mass parametrisation is present.
   :type parameters: dict
   :param minimum_frequency: Waveform starting frequency in Hz (used for non-EFPE waveforms).
   :type minimum_frequency: float
   :param approximant:
   :type approximant: str
   :param f22_start: For pyEFPE and pyEFPEHM waveforms, the frequency where the quadrupole
                     mode begins. When provided, used instead of minimum_frequency for
                     duration calculation. Default: None.
   :type f22_start: float or None
   :param maximum: Cap on the returned duration, in seconds.
   :type maximum: float or None
   :param minimum: Floor on the returned duration, in seconds.
   :type minimum: float or None

   :returns: Duration in seconds, rounded up to a power of two.
   :rtype: float
