.. py:class:: PopulationModel

   Base class: a normalised density over event parameters, given hyper-parameters.

   :ivar parameter_names: Hyper-parameter names, in the order the score columns come out.
   :vartype parameter_names: list of str
   :ivar fiducial: Default hyper-parameter values.
   :vartype fiducial: dict
   :ivar event_keys: Keys the model requires in the ``events`` dict.

   :vartype event_keys: list of str

      :value: []



   .. py:attribute:: fiducial


   .. py:attribute:: event_keys
      :value: []



   .. py:method:: log_prob(events, parameters)
      :abstractmethod:


      Log density of each event.

      :param events: Arrays of event parameters, all the same length.
      :type events: dict
      :param parameters: Hyper-parameter values; must cover :attr:`parameter_names`.
      :type parameters: dict

      :returns: Shape ``(n_events,)``. ``-inf`` outside the support.
      :rtype: numpy.ndarray



   .. py:method:: analytic_score(events, parameters)

      Closed-form score, or ``None`` if this model has none.

      :returns: Shape ``(n_events, len(parameter_names))``, columns in
                :attr:`parameter_names` order.
      :rtype: numpy.ndarray or None



   .. py:method:: score(events, parameters=None, method='auto')

      Score of each event with respect to every hyper-parameter.

      :param events:
      :type events: dict
      :param parameters: Defaults to :attr:`fiducial`.
      :type parameters: dict or None
      :param method: One of :data:`SCORE_METHODS`. ``"auto"`` tries analytic, then falls
                     back to finite differences.
      :type method: str

      :returns: Shape ``(n_events, len(parameter_names))``.
      :rtype: numpy.ndarray



   .. py:method:: to_vector(parameters)

      Hyper-parameter dict to array, in :attr:`parameter_names` order.



   .. py:method:: from_vector(vector, parameters=None)

      Array back to a hyper-parameter dict, merged onto ``parameters``.



   .. py:method:: check_events(events)

      Raise if ``events`` is missing a key this model needs.
