.. py:class:: Catalogue(events, network_snr, detectors, snr_threshold, n_total, n_with_snr)

   A detected catalogue, and the counts that describe how it was cut.

   :ivar events: Source parameters of the detected events, plus derived ``mass_ratio``
                 and ``cos_tilt_1``/``cos_tilt_2`` where the inputs allow.
   :vartype events: dict
   :ivar network_snr: Network optimal SNR of the detected events.
   :vartype network_snr: numpy.ndarray
   :ivar detectors: Detector columns that went into the network SNR.
   :vartype detectors: list of str
   :ivar snr_threshold:
   :vartype snr_threshold: float
   :ivar n_total: Injections in the population file.
   :vartype n_total: int
   :ivar n_with_snr: Injections the SNR stage actually covered.
   :vartype n_with_snr: int
   :ivar n_detected: Injections above threshold. GWForge applies no duty cycle, so this is
                     also the analysis sample.

   :vartype n_detected: int

.. py:function:: network_snr_from(snr_data, detectors=None)

   Quadrature sum of the per-detector optimal SNRs.

   :param snr_data: As written by ``gwforge_optimal_snr``.
   :type snr_data: dict
   :param detectors: Detector names (triangles already expanded). Defaults to every
                     ``*_optimal_snr`` column in the file.
   :type detectors: sequence of str or None

   :returns: ``(network_snr, detectors_used)``.
   :rtype: tuple

   :raises KeyError: If a requested detector has no column.

.. py:function:: load_catalogue(population_file, snr_file, snr_threshold=10.0, detectors=None, keys=CATALOGUE_KEYS)

   Join a population file to its SNR file and cut on network SNR.

   :param population_file: HDF5 from ``gwforge_population``.
   :type population_file: str
   :param snr_file: HDF5 from ``gwforge_optimal_snr``.
   :type snr_file: str
   :param snr_threshold: Network optimal-SNR threshold for detection.
   :type snr_threshold: float
   :param detectors: Detectors to sum. ``"ET"`` is expanded to its three arms. Defaults to
                     every detector in the SNR file.
   :type detectors: sequence of str or None
   :param keys: Source parameters to carry over.
   :type keys: sequence of str

   :rtype: Catalogue

   :raises ValueError: If the two files cannot be aligned, or nothing passes the threshold.
