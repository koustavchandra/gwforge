.. py:function:: corner_plot(results, save=None, title=None, seed=None, parameters=None, colours=None, palette_name='tealrose')

   Corner plot of one or more population Fisher forecasts, overlaid.

   :param results: ``(label, PopulationFisherResult)`` pairs. Every result must expose the
                   same free parameters, so that overlaying them compares like with like.
   :type results: sequence of tuple
   :param save: Path to write to. The figure is closed after saving.
   :type save: str or None
   :param title:
   :type title: str or None
   :param seed: Each dataset is drawn with a **freshly seeded** generator, so they share
                the same underlying standard normals and the contours nest visually
                instead of jittering independently against each other.
   :type seed: int or None
   :param parameters: Restrict the plot to these. Drawn from the *marginal* of the full
                      covariance, so the contours are marginalised, not the conditional ones a
                      re-fit over a subset would give. Defaults to all of them, which is
                      unreadable beyond about eight.
   :type parameters: sequence of str or None
   :param colours: One per dataset. Defaults to the palette's cycle, which starts
                   teal/rose.
   :type colours: sequence of str or None
   :param palette_name: ``"tealrose"`` or ``"okabe-ito"``.
   :type palette_name: str

   :rtype: matplotlib.figure.Figure

   :raises ValueError: If the results do not share their parameter list, or a requested
       parameter is not among them.
