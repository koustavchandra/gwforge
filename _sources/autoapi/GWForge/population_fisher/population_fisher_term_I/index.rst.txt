.. py:class:: PopulationFisherResult(parameter_names, fixed_parameters, fiducial, fisher, covariance, condition_number, n_events, n_total, scores, mean_score, degenerate)

   Everything :func:`population_fisher` computed, and how to read it.

   :ivar parameter_names: Free hyper-parameters, in matrix order.
   :vartype parameter_names: list of str
   :ivar fixed_parameters: Hyper-parameters held fixed, excluded from the matrix.
   :vartype fixed_parameters: dict
   :ivar fiducial: Values the Fisher was evaluated at, free and fixed together.
   :vartype fiducial: dict
   :ivar fisher: ``(n, n)`` Term-I Fisher matrix.
   :vartype fisher: numpy.ndarray
   :ivar covariance: Its inverse (or pseudo-inverse).
   :vartype covariance: numpy.ndarray
   :ivar sigma: Name to one-sigma marginalised uncertainty.
   :vartype sigma: dict
   :ivar condition_number:
   :vartype condition_number: float
   :ivar n_events: Events with finite scores, i.e. those that entered the sum.
   :vartype n_events: int
   :ivar n_total: Events offered, before the support and finiteness cuts.
   :vartype n_total: int
   :ivar scores: ``(n_events, n)`` raw, uncentred scores.
   :vartype scores: numpy.ndarray
   :ivar mean_score: ``(n,)``; the Monte-Carlo estimate of ``d ln alpha / d Lambda``.
   :vartype mean_score: numpy.ndarray
   :ivar degenerate: Free parameters whose centred score vanished.

   :vartype degenerate: list of str

.. py:function:: population_fisher(model, events, free_parameters=None, fixed_parameters=None, parameters=None, method='auto', rcond=DEFAULT_RCOND, n_total=None)

   Term-I population Fisher matrix for a detected catalogue.

   :param model:
   :type model: GWForge.population_fisher.base.PopulationModel
   :param events: Source parameters of the **detected** events. They must be drawn from
                  the population at ``parameters``, or the centred-score identity that
                  supplies the selection term does not hold.
   :type events: dict
   :param free_parameters: Hyper-parameters to vary. Defaults to every name the model has that is
                           not in ``fixed_parameters``.
   :type free_parameters: sequence of str or None
   :param fixed_parameters: Name to value, held fixed and excluded from the matrix.
   :type fixed_parameters: dict or None
   :param parameters: Fiducial point. Defaults to ``model.fiducial``.
   :type parameters: dict or None
   :param method: Passed to :meth:`~GWForge.population_fisher.base.PopulationModel.score`.
   :type method: str
   :param rcond: Pseudo-inverse threshold.
   :type rcond: float
   :param n_total: Events offered before cuts, for reporting. Defaults to ``len(events)``.
   :type n_total: int or None

   :rtype: PopulationFisherResult

   :raises ValueError: If no parameters are free, or no event has a finite score.
