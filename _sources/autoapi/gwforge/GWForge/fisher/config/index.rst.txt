.. py:function:: prior_settings(config, order, section='Priors')

   Read the ``[Priors]`` section and enforce the order-dependent rule.

   Order 1 is a closed-form covariance and needs no prior; order 2 samples a
   truncated Taylor expansion, which is only meaningful inside bounds, so a
   prior file is required there.

   :param config:
   :type config: configparser.ConfigParser
   :param order: Expansion order, from :func:`fisher_settings`.
   :type order: int
   :param section:
   :type section: str

   :returns: With keys ``prior_file`` and ``enforce_physicality``.
   :rtype: dict

   :raises ValueError: If ``order >= 2`` and no ``prior-file`` is given.


.. py:function:: _aligned_spin(parameters, component)

   Aligned spin component, however the parameters happen to spell it.

   ``convert_to_lal_binary_black_hole_parameters`` produces ``a_1`` and
   ``cos_tilt_1`` rather than ``spin_1z``, so reading ``spin_1z`` alone
   silently treats every binary as non-spinning and shortens the estimated
   duration.


.. py:function:: segment_duration(parameters, minimum_frequency, approximant, maximum=None)

   Segment length long enough to hold the signal.

   Getting this wrong is not a subtle error: a segment shorter than the inspiral wraps it, and the
   resulting derivatives are meaningless.

   :param parameters: Source parameters; needs component masses and aligned spins, which are
                      derived from whatever mass parametrisation is present.
   :type parameters: dict
   :param minimum_frequency: Waveform starting frequency in Hz.
   :type minimum_frequency: float
   :param approximant:
   :type approximant: str
   :param maximum: Cap on the returned duration, in seconds.
   :type maximum: float or None

   :returns: Duration in seconds, rounded up to a power of two.
   :rtype: float
