.. py:function:: primary_mass_grid_nodes(parameters, minimum_mass, maximum_mass)

   Number of primary-mass grid nodes needed to resolve the narrowest peak.

   The smoothed mass models are sampled by wrapping the density in a
   :class:`bilby.core.prior.Interped`, which builds a **linear interpolant** on
   this grid and inverse-CDF samples from that. The interpolant, not the
   density, is what the catalogue is drawn from, so the grid has to resolve
   every feature the density has.

   :param parameters: Mass-model parameters. Any key beginning with ``sigpp`` is treated as a
                      peak width; models without peaks keep the floor.
   :type parameters: dict
   :param minimum_mass: Range the grid spans.
   :type minimum_mass: float
   :param maximum_mass: Range the grid spans.
   :type maximum_mass: float

   :returns: Clipped to ``[MINIMUM_MASS_GRID_NODES, MAXIMUM_MASS_GRID_NODES]``.
   :rtype: int


.. py:function:: sample_mass_ratio_given_primary(model, primary_samples, mass_ratio_parameters, random_state=None)

   Draw ``mass_ratio`` conditionally on ``mass_1``, by inverse CDF.

   :param model: Supplies the ``m1s``/``qs`` grids and ``p_q``.
   :type model: BaseSmoothedMassDistribution
   :param primary_samples: Sampled ``mass_1_source``.
   :type primary_samples: array_like
   :param mass_ratio_parameters: ``beta``, ``mmin`` and ``delta_m``, and optionally ``mmin_2`` and
                                 ``delta_m_2`` for models whose secondary has its own taper.
   :type mass_ratio_parameters: dict
   :param random_state: Defaults to numpy's global RNG, so a single seed governs it.
   :type random_state: numpy.random.Generator or None

   :returns: Mass-ratio samples, the same length as ``primary_samples``.
   :rtype: numpy.ndarray
