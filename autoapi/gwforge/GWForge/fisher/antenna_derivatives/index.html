gwforge.GWForge.fisher.antenna_derivatives¶

Closed-form derivatives of the detector response geometry.

ra, dec and psi reach the strain only through the detector projection, never through the waveform, so their derivatives can be written down exactly. This module differentiates the same expressions GWForge.ifo.antenna.antenna_response() evaluates – the u, v, m and n triad, the propagation direction, the finite-size arm transfer function and the vertex delay – with respect to the internal angles \((\phi, \theta, \psi)\), and chain-rules them onto the source parameters.

That holds under the frequency-dependent, Earth-rotating response too, which changes only how \(F_{+,\times}\) and \(\tau\) are built. Freezing the polarizations and differencing the response alone reproduces the full derivative bit-identically; tests/test_fisher.py asserts exactly that.

The work is done on scalars rather than on \(3\times3\times n\) polarization tensors: contracting an arm with the polarization basis reduces to \((\hat a\cdot m)\) and \((\hat a\cdot n)\), so only those and their derivatives are ever needed.

gwforge.GWForge.fisher.antenna_derivatives._sinc_derivatives(z)[source]¶

Return (sinc, sinc', sinc'') for \(\mathrm{sinc}(z)\).

Uses numpy’s convention \(\mathrm{sinc}(z) = \sin(\pi z)/(\pi z)\), to match GWForge.ifo.antenna.finite_size_factor().

Both derivatives are singular-looking at z = 0 (they contain 1/z and 1/z**2) while being perfectly finite there, so small arguments are evaluated from the Taylor series instead.

gwforge.GWForge.fisher.antenna_derivatives._polarization_projections(basis, psi, arm)[source]¶

Project the polarization triad onto one arm, with all derivatives.

Rather than forming \(3\times3\times n\) polarization tensors and contracting them, note that

\[\tfrac{1}{2}\hat a\otimes\hat a : e^+ = \tfrac{1}{2}\big[(\hat a\cdot m)^2 - (\hat a\cdot n)^2\big], \qquad \tfrac{1}{2}\hat a\otimes\hat a : e^\times = (\hat a\cdot m)(\hat a\cdot n),\]

so everything reduces to the two scalars \(\hat a\cdot m\) and \(\hat a\cdot n\) and their derivatives.

Parameters:

  • basis (dict) – Output of _basis_derivatives().

  • psi (float) – Polarisation angle.

  • arm (numpy.ndarray) – Unit vector along the arm.

Returns:

(plus, cross), each keyed by the labels in _LABELS.

Return type:

tuple of dict

class gwforge.GWForge.fisher.antenna_derivatives.AntennaDerivatives(interferometer, ra, dec, geocent_time, psi, frequencies, start_time, times_to_coalescence=None, earth_rotation=True, finite_size=True)[source]¶

Exact derivatives of \(F_+\), \(F_\times\) and \(\tau\).

Differentiates the same expressions GWForge.ifo.antenna.antenna_response() evaluates, with respect to the internal angles \((\phi, \theta, \psi)\), then chain-rules those onto the source parameters ra, dec, psi and geocent_time:

\[\frac{\partial}{\partial\alpha} = \frac{\partial}{\partial\phi}, \qquad \frac{\partial}{\partial\delta} = -\frac{\partial}{\partial\theta}, \qquad \frac{\partial}{\partial t_c} \supset -\dot{\mathrm{gmst}}\,\frac{\partial}{\partial\phi},\]

the last because \(\phi = \alpha - \mathrm{gmst}(t_c)\). So the Earth-rotation part of the geocent_time derivative comes free from the sky partials. geocent_time additionally enters \(\tau\) explicitly with unit derivative, which is the dominant \(-2\pi i f h\) term.

plus, cross

\(F_+\) and \(F_\times\) and their derivatives, keyed by source parameter name ("ra") or sorted pair (("dec", "ra")).

gwforge.GWForge.fisher.antenna_derivatives._arm_transfer(basis, arm, arm_length_in_wavelengths)[source]¶

Finite-size transfer function for one arm, with angular derivatives.

The arm enters only through \(y = -\hat\Omega\cdot\hat a\), so the chain rule is one-dimensional: \(\partial_a D = D_y\,\partial_a y\) and \(\partial_{ab} D = D_{yy}\,\partial_a y\,\partial_b y + D_y\,\partial_{ab} y\).

Parameters:

  • basis (dict) – Output of _basis_derivatives().

  • arm (numpy.ndarray) – Unit vector along the arm.
