gwforge.GWForge.fisher.dali¶

Doublet-DALI likelihood and posterior sampling.

At order = 1 the log-likelihood is exactly quadratic, so the Fisher posterior is Gaussian and \(\Sigma = F^{-1}\) describes it completely – every marginal is an ellipse available in closed form.

The doublet adds cubic and quartic terms,

\[\log L = -\tfrac{1}{2}F_{ab}\Delta^a\Delta^b - \tfrac{1}{2}G_{abc}\Delta^a\Delta^b\Delta^c - \tfrac{1}{8}H_{abcd}\Delta^a\Delta^b\Delta^c\Delta^d,\]

which has neither a closed-form normalisation nor closed-form marginals.

The contractions are written as flattened matrix products rather than numpy.einsum() so they reach BLAS: measured at 1.9 million evaluations per second versus 0.03 million for the equivalent einsum call.

gwforge.GWForge.fisher.dali.build_priors(prior_file, names, fiducial, enforce_physicality=False, sigmas=None)[source]¶

Load and validate the sampling priors.

Parameters:

  • prior_file (str) – Path to a bilby .prior file.

  • names (sequence of str) – Fisher parameter names that must all be covered.

  • fiducial (dict) – Fiducial values, checked to lie inside the prior support – a prior that excludes the point the expansion is about would be sampling nothing.

  • enforce_physicality (bool) – Also reject samples outside PHYSICAL_RANGES.

  • sigmas (dict or None) – Fisher one-sigma widths. When given, priors narrower than NARROW_PRIOR_SIGMAS sigmas are warned about.

Return type:

bilby.core.prior.PriorDict

Raises:

  • KeyError – If the file does not define every parameter. bilby’s own prior files use mass_ratio, a_1 and friends, which do not line up with the default Fisher parameters, so this is a likely mistake and is worth failing loudly for rather than silently sampling the wrong space.

  • ValueError – If a fiducial value falls outside its prior.
