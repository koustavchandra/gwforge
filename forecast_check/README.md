# Population forecast check

End-to-end check of `gwforge_population_fisher` on a fresh one-year BGP + Default-spin +
Madau-Dickinson (⊗ 1/τ delay) BBH population, compared with the CE_STM_CBC reference
forecast and with Procedure 1 of the delay-time notes (effective Madau-Dickinson parameters
fitted to all injected redshifts, Term-I population Fisher as covariance, grid posterior on
(α, τ_min) with the SFR pinned). Run from this directory with
`P=/opt/anaconda3/envs/gwforge/bin/python`; the delay-time step needs the untracked
`../time_delay_forecasting_for_bbhs` (its `forecast.py` and `time_delay_model.py`).

```bash
$P ../bin/gwforge_population --config-file ../GWForge/population/population_configuration_files/bgp-gwtc5.ini \
    --output-file bbh_population.h5 --source-type bbh --reference-frequency 5 --seed 250114 --save-config
$P ../validation/gwtc5_population_check.py --population bbh_population.h5 \
    --config ../GWForge/population/population_configuration_files/bgp-gwtc5.ini --output-directory population_check

# about 1.5 and 2 hours on 10 cores
$P ../bin/gwforge_optimal_snr --injection-file bbh_population.h5 --output-file snr_xg.h5 --ifos CE40 CE20 ET \
    --waveform-approximant IMRPhenomXPHM --minimum-frequency 5 --sampling-frequency 4096 --cores 10
$P ../bin/gwforge_optimal_snr --injection-file bbh_population.h5 --output-file snr_2l.h5 --ifos CE40 ETSL ETMRL LI \
    --waveform-approximant IMRPhenomXPHM --minimum-frequency 5 --sampling-frequency 4096 --cores 10
$P ../validation/population_detection_fraction.py --population bbh_population.h5 --snr snr_xg.h5 \
    --detectors CE40 CE20 ET --snr-thresholds 10 20 --output-directory detection_fraction_xg

$P ../bin/gwforge_population_fisher --config-file mrs_xg.ini
$P ../bin/gwforge_population_fisher --config-file mrs_2l.ini
$P ../bin/gwforge_population_fisher --compare "CE40+CE20+ET=pf_xg/mrs_xg_snr10.npz" "CE40+ET2L+LI=pf_2l/mrs_2l_snr10.npz" \
    --parameters "['gamma','kappa','z_peak','alpha_1','mpp_1','mu_chi']" --output-file compare_networks.pdf

# about 7 minutes each (241 x 281 grid)
$P single_channel_forecast.py --result pf_xg/mrs_xg_snr10.npz --label CE40+CE20+ET
$P single_channel_forecast.py --result pf_2l/mrs_2l_snr10.npz --label CE40+ET2L+LI
$P compare_with_reference.py            # writes COMPARISON.md
```

`COMPARISON.md` holds the result; everything else here is regenerated by the commands above.
